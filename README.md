# ClassFolio · สมุดวัดผล ปพ.5 · คู่มือติดตั้ง

ระบบบันทึกคะแนนและจัดทำ ปพ.5 (ประถม/มัธยม) สำหรับครูผู้สอน ระยะที่ 1

## สิ่งที่อยู่ในชุดนี้

| ไฟล์ | หน้าที่ |
|---|---|
| `public/index.html` | หน้าเว็บหลัก |
| `public/firebase-config.js` | **ครูแก้ไฟล์นี้ไฟล์เดียว** ใส่ค่า Firebase และอีเมลครู |
| `public/calc.js` | สูตรแปลงคะแนน ตัดเกรด มส ร |
| `public/app.js`, `views.js`, `print.js`, `util.js`, `demo.js` | หน้าจอ เอกสาร ปพ.5 ข้อมูลตัวอย่าง |
| `public/platform.js` | ตัวเชื่อม Firebase (หรือเก็บในเครื่องถ้ายังไม่ตั้งค่า) |
| `public/fonts/`, `fonts.css` | ฟอนต์เล่มรายงาน TH SarabunPSK (ฝังมากับระบบ) |
| `public/sw.js`, `manifest.webmanifest`, `icon.svg` | ติดตั้งเป็นไอคอนบนมือถือ/คอม และเปิดได้ตอนเน็ตหลุด |
| `firestore.rules` | กฎความปลอดภัย ครูเห็นเฉพาะข้อมูลของตัวเอง |
| `vercel.json` | ตั้งค่า Vercel |
| `AI_GUIDE.md` | คู่มือโครงสร้างโค้ด สำหรับให้ AI (เช่น Antigravity) แก้ต่อ |

## ขั้นที่ 1 · ทดลองในเครื่องก่อน (ไม่บังคับ)

ดับเบิลคลิก `public/index.html` เปิดด้วย Chrome ได้เลย ระบบจะอยู่ใน "โหมดทดลอง" มีข้อมูลตัวอย่าง 2 วิชา ข้อมูลเก็บในเบราว์เซอร์นั้น

## ขั้นที่ 2 · สร้างโปรเจกต์ Firebase

1. เข้า https://console.firebase.google.com › **Add project** › ตั้งชื่อ เช่น `samutwadphon` (ปิด Google Analytics ได้)
2. เมนู **Build › Authentication › Get started › Sign-in method** › เปิด **Google** › ใส่อีเมลครู › Save
3. เมนู **Build › Firestore Database › Create database** › เลือก Location `asia-southeast1 (Singapore)` › **Start in production mode**
4. แท็บ **Rules** ของ Firestore › ลบของเดิม › วางเนื้อหาไฟล์ `firestore.rules` › แก้อีเมลใน `teacherEmails()` › **Publish**
5. ไอคอนฟันเฟือง **Project settings › Your apps** › กดไอคอน `</>` (Web) › ตั้งชื่อแอป › Register › คัดลอกค่า `firebaseConfig`

## ขั้นที่ 3 · ใส่ค่าในไฟล์ firebase-config.js

เปิด `public/firebase-config.js` แล้ววางค่า เช่น

```js
window.FIREBASE_CONFIG = {
  apiKey: "AIza...",
  authDomain: "samutwadphon.firebaseapp.com",
  projectId: "samutwadphon",
  storageBucket: "samutwadphon.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abc123"
};
window.TEACHER_EMAILS = ["อีเมลครู@gmail.com"];
```

อีเมลต้องตรงกับใน `firestore.rules`

## ขั้นที่ 4 · ขึ้น GitHub และ Vercel

1. สร้าง repository ใหม่ใน GitHub เช่น `samutwadphon` › อัปโหลดไฟล์ทั้งหมดในชุดนี้ (ทั้งโฟลเดอร์ `public` และไฟล์ด้านนอก)
2. เข้า https://vercel.com › **Add New › Project** › เลือก repository › Framework Preset: **Other** › **Deploy**
3. ได้ลิงก์ เช่น `samutwadphon.vercel.app`
4. กลับไป Firebase › **Authentication › Settings › Authorized domains** › **Add domain** › ใส่ `samutwadphon.vercel.app`

## ขั้นที่ 5 · เริ่มใช้งาน

1. เปิดลิงก์ › เข้าสู่ระบบด้วย Google
2. **ตั้งค่า** › ใส่ชื่อโรงเรียน ตราโรงเรียน ผู้ลงนาม
3. **สร้างรายวิชา** › ใส่รหัสวิชา (ตัวเลขตัวแรก 1 = ประถม, 2–3 = มัธยม)
4. **นักเรียน** › วางรายชื่อจาก Excel
5. **โครงสร้างรายวิชา** › หน่วยและน้ำหนักคะแนน (ระหว่างเรียนต้องรวมได้ตามสัดส่วน เช่น 70)
6. **สมุดคะแนน** › เพิ่มงานตามคะแนนเต็มจริง กรอก/วางคะแนน ระบบแปลงเข้า ปพ.5 ให้เอง
7. **ปพ.5** › พิมพ์ หรือบันทึกเป็น PDF (หน้าต่างพิมพ์: A4, ระยะขอบ "ไม่มี", เปิด "กราฟิกพื้นหลัง")
8. **ส่งออก Excel** (หน้าตัดเกรด หรือหน้า ปพ.5) › ได้ไฟล์ 4 ชีต: สรุปผลการเรียน · สมุดคะแนนดิบ · เวลาเรียนรายคาบ · บันทึกการสอน ใช้ส่งงานทะเบียนหรือนำเข้าระบบโรงเรียน

## เวลาเรียน

เช็คชื่อใน Live Class 1 ครั้ง = 1 คาบ (ตั้งได้ว่า 1 คาบกี่ชั่วโมง ที่ ตารางสอน › ตั้งวันและคาบเรียน) ระบบหักชั่วโมงขาดให้เอง ระบบแสดงตัวเลข 2 ชุด
- **มาแล้ว** เช่น 8/10 คาบ · 80% คิดจากคาบที่สอนไปแล้ว ใช้ดูตั้งแต่ต้นภาคว่าใครเริ่มขาดบ่อย ถ้าต่ำกว่าเกณฑ์ (สอนแล้วตั้งแต่ 3 คาบ) ขึ้นในรายชื่อนักเรียนที่ควรติดตามด่วนบนหน้าแรก
- **ทั้งภาค** คิดจากชั่วโมงเต็มของวิชา ใช้ตัดสิน มส และพิมพ์ใน ปพ.5

## ใช้หลายเครื่องพร้อมกัน

เปิดได้ทั้งคอม แท็บเล็ต และมือถือพร้อมกัน ข้อมูลอัปเดตถึงกันเองภายในไม่กี่วินาที เช่น เช็คชื่อในมือถือ ขณะกรอกคะแนนในคอม ทั้งสองอย่างจะถูกเก็บครบ ไม่ทับกัน ถ้าแก้ช่องเดียวกันพร้อมกัน ค่าที่บันทึกทีหลังจะถูกใช้ ระหว่างที่กำลังพิมพ์ ระบบรอให้พิมพ์เสร็จก่อนแล้วจึงแสดงข้อมูลใหม่

## เริ่มภาคเรียนใหม่

หน้าแรก › **เริ่มภาคเรียนใหม่** เลือกรายวิชาที่สอนต่อ แก้รหัสวิชา ชื่อ ชั้น ห้องได้ (เช่น ส21101 → ส21102) เลือกว่าจะคัดลอกรายชื่อ โครงสร้าง คำอธิบายรายวิชา และย้ายตารางสอนไปด้วยหรือไม่ ระบบสร้างวิชาใหม่ที่คะแนนว่าง และย้ายวิชาเดิมเข้า **คลังภาคเรียนเก่า** (ท้ายหน้าแรก) ซึ่งยังเปิดดู แก้ พิมพ์ ปพ.5 และส่งออก Excel ได้ตลอด นำกลับมาใช้งานได้ทุกเมื่อ

## ติดตั้งเป็นแอป

กดปุ่ม **ติดตั้งเป็นแอป** ที่หน้าแรกสุด ที่ตั้งค่า หรือในเมนูเพิ่มเติม
- Android / คอม (Chrome, Edge): ระบบเปิดหน้าต่างติดตั้งให้ทันที
- iPhone / iPad: เปิดด้วย Safari แล้วแตะ แชร์ › เพิ่มไปยังหน้าจอโฮม (ระบบแสดงวิธีให้)

ต้องเปิดจากลิงก์ Vercel (https) เท่านั้น หน้าตัวอย่างบน claude.ai ติดตั้งไม่ได้

## การสำรองข้อมูล

ระบบสำรองให้อัตโนมัติวันละ 1 ครั้ง เก็บย้อนหลัง 14 วันใน Firebase กู้คืนได้ที่ **ตั้งค่า › การสำรองข้อมูล** (ก่อนกู้คืน ระบบสำรองข้อมูลปัจจุบันไว้ให้ก่อนเสมอ) ถ้าต้องการเก็บสำเนาไว้ในเครื่องเอง เปิด **ตัวเลือกเพิ่มเติม › ดาวน์โหลดสำเนาเก็บเอง**

## ใครเข้าระบบได้บ้าง

ลิงก์ Vercel เปิดได้ทุกคน แต่จะเห็นเพียงหน้าแรกสุด เข้าสู่ระบบได้เฉพาะอีเมลที่ใส่ไว้ใน `firebase-config.js` และ `firestore.rules` ส่วนฐานข้อมูลก็อ่านได้เฉพาะเจ้าของ ถ้าต้องการให้ครูท่านอื่นใช้ ให้เพิ่มอีเมลในทั้งสองไฟล์ (แต่ละคนเห็นเฉพาะข้อมูลของตัวเอง)

## ข้อมูลจากโหมดทดลอง

ถ้ากรอกข้อมูลจริงในโหมดทดลองไปแล้ว ให้กดสำรองข้อมูลในเครื่องเดิมก่อน แล้วนำเข้าไฟล์นั้นหลังเข้าสู่ระบบบน Vercel

## ใส่ภาพหน้าแรกของครูเอง

วางไฟล์ภาพชื่อ `hero.png` ไว้ในโฟลเดอร์ `public` (แนะนำพื้นหลังโปร่งใส ขนาด 1536×1024) ระบบจะแสดงภาพนี้แทนการ์ดตัวอย่างโดยอัตโนมัติ ทั้งบนคอม แท็บเล็ต และมือถือ ถ้าไม่มีไฟล์ ระบบใช้การ์ดตัวอย่างเดิม

## ถ้าเจอปัญหา

| ข้อความที่ขึ้น | วิธีแก้ |
|---|---|
| โดเมนนี้ยังไม่ได้รับอนุญาต | Firebase › Authentication › Settings › Authorized domains › เพิ่มโดเมน `xxx.vercel.app` |
| ยังไม่ได้เปิดการเข้าสู่ระบบด้วย Google | Firebase › Authentication › Sign-in method › เปิด Google |
| บัญชี ... ยังไม่ได้รับสิทธิ์ใช้ระบบนี้ | อีเมลไม่ตรงกับ `firebase-config.js` หรือ `firestore.rules` แก้ให้ตรงกันทั้งสองไฟล์ แล้ว Publish rules ใหม่ |
| เบราว์เซอร์บล็อกหน้าต่างเข้าสู่ระบบ | อนุญาตป๊อปอัปสำหรับเว็บนี้ แล้วกดเข้าสู่ระบบอีกครั้ง |
| บันทึกไม่สำเร็จ (Missing or insufficient permissions) | ยังไม่ได้ Publish `firestore.rules` หรืออีเมลในไฟล์ไม่ตรง |
| ยังเป็น "โหมดทดลอง" หลังขึ้น Vercel | `firebase-config.js` ยังเป็นค่า "ใส่ค่า ..." อยู่ วางค่าจริงจาก Firebase แล้ว commit ใหม่ |
| แก้ไฟล์แล้วหน้าเว็บไม่เปลี่ยน | ระบบเก็บไฟล์ไว้ในเครื่องเพื่อเปิดเร็ว ปิดแล้วเปิดใหม่ 2 ครั้ง หรือกด Ctrl+Shift+R |

## ก่อนเริ่มใช้งานจริง

1. เข้าสู่ระบบครั้งแรก ระบบจะว่างเปล่า (ไม่มีข้อมูลตัวอย่าง) เริ่มที่ **ตั้งค่า** ใส่ชื่อโรงเรียน ตรา และผู้ลงนาม
2. **ตารางสอน › ตั้งวันและคาบเรียน** ให้ตรงกับโรงเรียน
3. สร้างรายวิชา วางรายชื่อ แล้วเริ่มใช้ Live Class ได้เลย
4. ข้อมูลที่ทดลองกรอกในหน้าตัวอย่างบน claude.ai ไม่ย้ายมาเอง ถ้าต้องการ ใช้ ตั้งค่า › ตัวเลือกเพิ่มเติม › ดาวน์โหลดสำเนา แล้วนำเข้าในระบบจริง
